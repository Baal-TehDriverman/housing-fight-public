# VIOLATIONS — Laws we believe were broken

**Scope:** This folder consolidates the statutes and legal theories Eric's
case file identifies as violated by the landlord (Cedar Lane Mobile Estates
LLC / Hurst & Son LLC) and by the home seller (Ron'Cal Homes LLC). It is a
working list for counsel, not a filing. Each entry cites the statute, the
alleged conduct, the evidence pointer in this repo, and an honest status.

**Status legend:**
- **VERIFIED** — read verbatim from the statute text this session; discrepancy
  with the landlord's documents is documented.
- **ALLEGED** — supported by repo evidence but not yet established in a
  proceeding; plead as allegation, not conclusion.
- **CANDIDATE** — theory worth exploring with counsel; evidence incomplete.
- **NOT ESTABLISHED** — considered and rejected or unproven; do not plead.

**Companion files:** `landlord-side.md` (Cedar Lane / Hurst & Son),
`home-seller-side.md` (Ron'Cal Homes LLC).

**Standing caution:** several notes in this repo contradict each other.
Where this folder and an older note disagree, this folder states the
evidence and the disagreement; it does not silently prefer one. See
`notes/corrections-2026-10-28.md` and `notes/fact-check-2026-10-24.md`.

**Nothing here has been filed or sent.** Drafts are review-only.
